# UC Companion

Daily symptom and wellness tracker for ulcerative colitis (IBD).

## Features

- Daily symptom tracking (pain, blood, urgency, fatigue, nausea, appetite)
- Bathroom visit counter
- Food and trigger logging
- Medication management with reminders
- Infusion/appointment scheduling with Google Calendar integration
- Data export (JSON/CSV)
- Offline-first — works without internet

## Usage

Open `index.html` in any browser. All data is stored locally in your browser.
